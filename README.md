## 🛠️ [나만의 Skills](나만의%20Skills)

- [**Backend 레벨 별 관심사 Matrix**](나만의%20Skills/Backend%20레벨%20별%20관심사%20Matrix.md)
  요청이 지나가는 스택의 위치(레벨)마다 보안·성능·가용성·관찰성·비용·컴플라이언스(관심사)를 무엇을 챙겨야 하는지 정리한 체크리스트입니다.

  - 공통 주제: 관찰성·장애대응, CI/CD·배포 전략, 비용 최적화, 컴플라이언스
